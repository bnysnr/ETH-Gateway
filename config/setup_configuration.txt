can0 Schnittstelle aktivieren:
sudo ip link set can0 type can bitrate 250000
sudo ip link set up can0

Pican Konfiguration
1. sudo raspi-config
2. Interface Options --> SPI --> Enble
3. sudo reboot
4. sudo nano /boot/firmware/config.txt
Einfügen:
dtparam=spi=on
dtoverlay=mcp2515-can0,oscillator=16000000,interrupt=25
dtoverlay=spi-bcm2835-overlay



5. sudo reboot
6. ifconfig can0
7. sudo apt install can-utils -y
8. candump can0
